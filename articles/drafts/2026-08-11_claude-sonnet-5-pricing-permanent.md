# Sonnet 5の9月値上げは中止：$2/$10が標準価格に

※本記事は2026年8月11日時点の公開情報にもとづきます。料金・仕様は変わりやすいため、最新は公式ページでご確認ください。

## この記事でわかること

- Claude Sonnet 5の9月1日からの値上げ（$3/$15）が実施されなくなったこと
- 影響を受ける人と、受けない人の切り分け
- 単価が据え置きでも残る「実費が上がる要因」と、引き続き有効なコスト対策

## 1. 何が発表されたか

Anthropicは2026年8月10日、**Claude Sonnet 5の導入価格をそのまま標準価格にする**と公表しました。

公式のリリースノート（2026年8月10日付）には、次のように記載されています。

> The introductory pricing for Claude Sonnet 5 ($2 / $10 per MTok) is now the standard price: the previously scheduled increase to $3 / $15 per MTok on September 1, 2026 will not occur.

日本語にすると「Sonnet 5の導入価格（100万トークンあたり入力2ドル・出力10ドル）が標準価格になった。9月1日に予定されていた入力3ドル・出力15ドルへの引き上げは行われない」という内容です。

同じ趣旨の注記が、公式の価格ページと、6月30日公開の「Introducing Claude Sonnet 5」の記事にも追記されています。一次情報が3か所で一致しているため、確定情報として扱って差し支えないと考えます。

## 2. 前回お伝えした「9月値上げ」は撤回されました

このアカウントでは8月9日に、「Sonnet 5の導入価格が8月31日で終了し、9月1日から1.5倍になる」という記事を公開しました。**その前提は今回の発表で変わりました**ので、訂正してお伝えします。

8月9日時点では、公式の価格ページに9月1日からの標準価格として$3/$15が明記されていました。当時の記載にもとづく内容でしたが、その後Anthropic側が方針を変更した形です。9月に向けた値上げ対策を進めていた方は、いったん手を止めて問題ありません。

## 3. 現在の料金（2026年8月11日時点）

公式の価格ページに掲載されているClaude Sonnet 5の単価は次のとおりです。単位はすべて100万トークンあたりです。

- 基本の入力: 2ドル
- 出力: 10ドル
- キャッシュヒット・リフレッシュ: 0.20ドル
- 5分キャッシュの書き込み: 2.50ドル
- 1時間キャッシュの書き込み: 4ドル
- Batch API利用時: 入力1ドル / 出力5ドル

参考までに、他モデルの基本単価（入力 / 出力）も並べます。

- Claude Haiku 4.5: 1ドル / 5ドル
- Claude Sonnet 4.6: 3ドル / 15ドル
- Claude Opus 5: 5ドル / 25ドル
- Claude Fable 5: 10ドル / 50ドル

注目したいのは、**Sonnet 5が旧世代のSonnet 4.6より単価で安いまま固定された**点です。9月1日からの$3/$15はSonnet 4.6と同額でしたが、その並びにはならなくなりました。

金額感の目安として計算してみます。月に入力3,000万トークン・出力300万トークンを使う場合、$2/$10では入力60ドル・出力30ドルで合計90ドルです。$3/$15なら135ドルでした。差額は月45ドル、年間で540ドルになります。これは公開単価からの単純計算であり、実際の請求はキャッシュやBatchの利用状況で変わります。

## 4. 誰に影響するか

**影響がある人**

- Claude APIをAPIキーで従量課金利用している方
- LLMゲートウェイ経由でSonnet 5を使い、トークン単価で原価計算している方
- Sonnet 5を組み込んだツールやサービスを運用し、9月以降の値上げを価格に織り込んでいた方

3つ目に当てはまる方は、値上げ分を顧客価格に転嫁する予定だった場合、その根拠がなくなった点に注意が必要です。

**基本的に影響がない人**

- Claude Pro / Max / Team などの定額プランでClaude Codeやチャットを使っている方

定額プランの利用はトークン単価での課金ではないため、今回の変更が請求額に直接反映されるものではありません。

**各自で確認が必要な人**

- Amazon BedrockやGoogle Cloud経由で使っている方

これらはパートナーが運営するプラットフォームで、価格は各社の価格ページに掲載されます。今回の変更がそのまま反映されるかどうかは、本稿執筆時点で確認できていません。各社の価格ページをご確認ください。

Claude Platform on AWSとClaude in Microsoft Foundryは、公式ドキュメントによればClaude API標準単価で換算してCCU（Claude Consumption Unit）で請求されます。標準単価が変わらないため据え置きになると考えられますが、明示的な言及は確認できていません。

## 5. 単価が据え置きでも残る注意点

単価が変わらなくても、実費が上がるケースはあります。公式の価格ページには次の注記があります。

Claude 4.7以降のモデルは新しいトークナイザを使っており、**同じテキストでおよそ30%多いトークン**になります。増加幅は内容や処理の形によって変わります。Sonnet 4.6以前のモデルは従来のトークナイザです。

つまりSonnet 4.6からSonnet 5へ移行する場合、単価は3ドルから2ドルに下がりますが、トークン数が増えるぶん値下がり分の一部が相殺されます。単価は3分の2でも、請求が3分の2になるとは限らない点にご注意ください。実際の増減はワークロードによって変わるため、移行時は少量で試して実トークン数を確認するのが確実です。

なお、`inference_geo` を `"us"` に指定して米国内推論に限定すると、全カテゴリの単価が1.1倍になります。データ所在地の要件がある場合はこちらも計算に入れてください。

## 6. 引き続き有効なコスト対策

値上げがなくなっても、以下の手段の効果は変わりません。むしろ単価の変動幅より効く場面が多いと考えます。

**プロンプトキャッシュ**

キャッシュヒットは基本入力の0.1倍です。書き込みは5分キャッシュが1.25倍、1時間キャッシュが2倍かかります。公式ドキュメントの説明では、5分キャッシュは1回、1時間キャッシュは2回の読み出しで元が取れる計算です。同じシステムプロンプトや長い資料を繰り返し送る処理で効果が出ます。

**Batch API**

即時性が不要な処理を非同期に回すと、入力・出力とも50%割引になります。Sonnet 5なら入力1ドル・出力5ドルです。

**モデルの使い分け**

分類・抽出・整形のような単純な処理はHaiku 4.5に落とせます。単価は入力1ドル・出力5ドルで、Sonnet 5の半分です。

なお、Claude 4.6以降のモデルは1Mトークンのコンテキストウィンドウを標準価格のまま使えると明記されています。長いコンテキストへの追加の割増はありません。

## 7. あわせて：Compliance APIがローカルセッションに対応

2026年8月11日、Claude Enterprise組織向けのベータとして、Compliance APIが利用者のマシン上で動くCoworkおよびClaude Codeセッションのトランスクリプトを返すようになりました。個人プランの利用者に適用されるものではありませんが、会社のEnterprise契約でClaude Codeを使っている方は、セッション内容が組織側から取得され得る点を把握しておくとよいと考えます。

## 8. 筆者の見方

今回は、告知済みの値上げが実施前に撤回されるという、あまり多くないケースです。

背景について公式の説明は見当たりませんでした。ただ、7月30日にOpenAIがGPT-5.6を最大80%値下げしており、中価格帯の競争が激しくなっている状況と無関係ではないと推測します。これは筆者の見方であり、Anthropicが理由として述べたものではありません。

実務上の受け止め方としては、2点あると考えます。ひとつは、9月に向けて急いでいた移行やコスト削減の作業は、期限に追われる必要がなくなったこと。もうひとつは、公式ページに載っている将来の価格も変わり得るという前提で、原価計算は「現時点の単価」で組んでおくほうが安全だということです。

一方で、キャッシュとBatchの最適化は期限とは無関係に効きます。値上げ対策として着手していた方は、そのまま進めて損はないと考えます。
