対象読者：AIにコードを書かせてみたいが、Claude Code と Codex のどちらを使えばいいか決めかねている方

この記事で分かること：2つの関係、2026年8月時点の料金、無料で試せるかの差、決め方

## 先に結論

いま払っている月額で決めてください。

・ChatGPT に課金している → Codex（追加費用なしで使えます）
・Claude に課金している → Claude Code（同じく追加費用なし）
・どちらにも課金していない → まず ChatGPT の無料枠で Codex に触れてみる

性能で選ぼうとすると決まりません。この2つは同じ種類のツールで、しかも有料プランの価格が同じ月20ドルです。差が出るのは「あなたがすでにどちらの財布を開いているか」と「無料で試せるか」のところです。

## Codex とは何か

Codex は OpenAI のコーディング用エージェントです。公式ドキュメントの説明はこうです。ターミナルから離れずに、コードを調べ、変更を加え、コマンドを実行し、繰り返しの作業を自動化する。

これは Claude Code の説明とほぼ同じ内容です。Claude Code のほうも、コードベースを読み、ファイルを編集し、コマンドを実行するツールと公式に書かれています。

つまり2つは競合というより、同じジャンルの製品です。「AIが自分の代わりにファイルを触る」という体験そのものは、どちらを選んでも得られます。ここを「どっちが賢いか」で比べ始めると、初心者ほど決められなくなります。

## 料金（2026年8月27日時点）

Claude（公式ページはドル表記）

・Free：0ドル。Claude Code は含まれません
・Pro：月額20ドル（年払いなら実質17ドル、200ドル一括）。Claude Code はここから
・Max：100ドルから

Codex（公式ページはドル表記）

・Free：0ドル。「手早いコーディング作業で Codex の機能を試す」と書かれています
・Go：8ドル。「軽めのコーディング作業に Codex を使う」
・Plus：20ドル。ウェブ・CLI・IDE拡張・iOS での Codex 利用が明記されています
・Pro：100ドルから（Plus の5倍または20倍）

ChatGPT の日本語料金ページでは、Go が月額1,400円、Plus が3,000円、Pro が16,800円からと表示されます。

有料の入り口はどちらも20ドルで並びます。違うのはその下です。Codex 側には8ドルのプランがあり、Claude 側に同じ価格帯はありません。

## 無料で試せるかが、初心者には一番効く

ここが実質的な最大の差です。

Codex の公式料金ページには、Codex は Free / Go / Plus / Pro / Business / Edu / Enterprise の各プランに含まれる、と書かれています。ChatGPT の日本語料金ページでも、無料版の欄に「Codex へのアクセスに上限あり」と明記されています。つまり0円のまま、エージェントが自分のコードを触る感覚を確かめられます。

一方 Claude Code は、Free プランには含まれません。試すには最低でも Pro の20ドルが必要です。

ひとつ注意があります。無料プランの欄には、CLI で使えるとは書かれていません。ウェブ・CLI・IDE拡張・iOS という内訳が明記されているのは Plus 以上です。無料枠でどこまで触れるかは、申し込む前に公式で確認してください。

なお、どちらも月額プランではなく API の従量課金で使う道もあります。Codex は API キーでサインインでき、その場合はトークン量に応じた課金になります（クラウド側の機能は一部使えなくなると明記されています）。Claude Code も、サブスクリプションのかわりに Console のアカウントで使えると公式に書かれています。ただし従量課金は使った分だけ請求が伸びるので、最初の1本を作る段階では月額プランのほうが読みやすいはずです。

## 入り口はどちらもターミナルだけではない

「Codex CLI」「Claude Code」と聞くと黒い画面の話に見えますが、どちらもターミナル専用ではありません。

Claude Code は、ターミナル、VS Code、JetBrains、デスクトップアプリ、ブラウザから使えます。デスクトップアプリには Claude Code が同梱されているので、CLI を別に入れる必要はないと公式に書かれています（有料プランが必要です）。

Codex も、CLI のほかにデスクトップアプリ、ChatGPT のウェブ、IDE拡張、クラウド実行が用意されています。

導入コマンドは、どちらも1行です。Claude Code は claude.ai の install スクリプトを、Codex は chatgpt.com の install スクリプトを実行します。Windows にはそれぞれ別の手順が用意されているので、公式の該当タブを見てください。

## タイプ別の選び方

Codex から始めたほうがいい人

・すでに ChatGPT の Plus や Go を払っている
・まず0円で、エージェントに触ってみたい
・月額を8ドルに抑えたい

Claude Code から始めたほうがいい人

・すでに Claude Pro や Max を払っている
・ターミナル以外の入り口（デスクトップアプリ）から入りたい

どちらも払っていない人

ChatGPT の無料枠で Codex に触ってから決めるのが、金銭的に一番安全です。触ってみて「これは自分の作業に効く」と分かってから、20ドルをどちらに払うか決めればいい。順番を逆にすると、使わないサブスクだけが残ります。

そして、2つを同時に契約しないでください。うまくいかなかったときに、ツールが悪いのか自分の指示が悪いのかを切り分けられなくなります。まず片方で1本作り切る。それからです。

## まとめ

・Claude Code と Codex は同じジャンルのツール。体験の中心は変わらない
・有料の入り口はどちらも月20ドル。決め手は既存の課金先
・無料で試せるのは Codex 側（ただし無料プランの欄に CLI の記載はない）
・最安の有料プランは Codex 側の8ドル
・ターミナル専用ではない。どちらもアプリやIDEから使える

ツール選定は1日で終わらせて、残りの時間を「1本作り切ること」に使ってください。
