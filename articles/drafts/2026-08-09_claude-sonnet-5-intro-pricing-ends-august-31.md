# Sonnet 5の導入価格が8月31日で終了：9月からの備え

※本記事は2026年8月9日時点の公開情報にもとづきます。料金・仕様は変わりやすいため、最新は公式ページでご確認ください。

## この記事でわかること

- Claude Sonnet 5の導入価格が8月31日で終わり、9月1日から入力・出力とも5割上がること
- 影響を受ける人と、受けない人の切り分け
- 今週（8月5〜8日）追加された「支出に上限を決める」仕組みと、単価以外で効く3つの手段

## 1. 何が変わるのか

Claude Sonnet 5は2026年6月30日に公開されたモデルです。公開時から**導入価格（introductory pricing）**が適用されてきました。その期限が **2026年8月31日** です。9月1日からは標準価格に切り替わります。

公式の価格ページに記載されている数字は次のとおりです。単位はすべて100万トークンあたりです。

**8月31日まで（導入価格）**

- 基本の入力: 2ドル
- 出力: 10ドル
- 5分キャッシュの書き込み: 2.50ドル
- 1時間キャッシュの書き込み: 4ドル
- キャッシュヒット（読み出し）: 0.20ドル
- Batch API利用時: 入力1ドル / 出力5ドル

**9月1日から（標準価格）**

- 基本の入力: 3ドル
- 出力: 15ドル
- 5分キャッシュの書き込み: 3.75ドル
- 1時間キャッシュの書き込み: 6ドル
- キャッシュヒット（読み出し）: 0.30ドル
- Batch API利用時: 入力1.50ドル / 出力7.50ドル

つまり、キャッシュやBatchを含めて**一律1.5倍**です。公式ドキュメントには「導入価格は2026年8月31日まで有効で、その後は標準価格が適用される」と明記されています。

### 試算：どのくらい増えるか

仮に月間で入力3,000万トークン・出力300万トークンを素のまま流している場合で計算します。キャッシュもBatchも使わない前提です。

- 8月まで: 60ドル + 30ドル = **90ドル**
- 9月以降: 90ドル + 45ドル = **135ドル**

差額は月45ドルです。これは公開単価に掛け算しただけの試算で、実際の請求額は使い方で変わります。自分の直近1か月の使用量を1.5倍してみるのが、いちばん早い見積もりです。

### 「Sonnet 4.6と同額に戻る」だけではない点

9月以降のSonnet 5の単価（3ドル / 15ドル）は、Claude Sonnet 4.6やSonnet 4.5と同じ数字です。ただし、同じ文章を投げてもトークン数が一致するとは限りません。

公式の価格ページには、Claude 4.7以降のモデルが**新しいトークナイザ**を使うと注記されています。同じテキストでおよそ30%多いトークンを生成し、増加幅は内容によって変わるとのことです。Sonnet 4.6以前は従来のトークナイザです。

Sonnet 5の公開アナウンスでは、導入価格は「移行がおおむねコスト中立になるように設定した」と説明されています。裏を返すと、9月以降は単価表の数字だけで旧モデルと比較すると実感とずれる可能性があります。判断材料にするなら、単価ではなく**自分のワークロードでの実請求額**を見るのが確実です。

## 2. 影響を受ける人・受けない人

ここは切り分けが大事です。

**影響を受ける可能性が高い人**

- APIキーでClaude API（Anthropic直）を従量課金で使っている人
- 組織のLLMゲートウェイ経由でClaude Codeを使っている人（課金先はゲートウェイの資格情報の持ち主です）
- Sonnet 5を組み込んだ自作ツール・SaaSを運用している人

**基本的に影響しない人**

- Pro / Max などの定額プランのログインでClaude・Claude Codeを使っている人

公式のゲートウェイ関連ドキュメントには、ゲートウェイの資格情報が有効な間はclaude.aiのサブスクリプションが使われないと記載があります。そのトラフィックは資格情報の持ち主に**トークン単位で課金される**とのことです。逆にいえば、サブスクリプションのログインで使う限り、課金はトークン単価ではなくプランの使用量上限の枠組みで動きます。

**別途確認が必要な人**

- Amazon Bedrock、Google Cloud経由で使っている人

公式ドキュメントは、このパートナー運営の2つについては各社の価格ページを参照するよう案内しています。今回の日付がそのまま適用されるかは、本記事では確認できていません。各社のページでご確認ください。

なお Claude Platform on AWS と Microsoft Foundry は、Claude APIと同じ標準単価で算定した額をCCUという単位に換算して請求すると記載されています。この2つは同じ単価表に連動します。

## 3. 今週追加された「上限を決める」仕組み

値上げとは別の話ですが、支出をコントロールする機能が今週相次いで入りました。同じ時期の動きとして押さえておく価値があります。

### Managed Agentsのセッション予算（8月7日）

Claude Developer Platformのリリースノートによると、Managed Agentsのセッションに**予算（budget）**を設定できるようになりました。公開価格ベースでセッションの支出に上限を設ける仕組みです。

上限に達したセッションは、新しいモデルリクエストを始めません。代わりに `budget_reached` という停止理由で一時停止します。予算を変更または解除すれば再開します。デプロイメント側にも同じ予算を設定できます。

### Claude Codeのゲートウェイ支出上限の表示（8月8日）

Claude Code v2.1.225では、ゲートウェイの支出上限に対応した使用量警告が追加されました。上限に達したときのメッセージに、**上限の額・リセット時刻・運用者からのメッセージ**が表示されます。公式changelogには、ゲートウェイ側も2.1.225相当である必要があると記載されています。

**読者への影響**：組織のゲートウェイ経由で使っていて突然止まった経験がある人は、理由が画面に出るようになります。個人でAPIキーを直接使っている場合は、この2つはどちらも直接は関係しません。

## 4. 単価以外で効く3つの手段

単価が上がる分、使い方で戻せる余地があります。いずれも公式の価格ページに記載のある仕組みです。

**1. Batch API（50%割引）**

非同期でよい処理はBatch APIに寄せると、入力・出力とも50%引きになります。9月以降のSonnet 5なら入力1.50ドル / 出力7.50ドルです。これは値上げ前の素の単価（2ドル / 10ドル）より安い水準です。即時の応答が要らないバッチ処理・分類・要約は、ここに移すだけで効きます。

**2. プロンプトキャッシュ**

キャッシュヒットは基本入力価格の**0.1倍**です。書き込みは5分キャッシュが1.25倍、1時間キャッシュが2倍。公式ドキュメントは「5分キャッシュは1回読み出せば元が取れ、1時間キャッシュは2回で元が取れる」と説明しています。長いシステムプロンプトや資料を毎回投げているなら、ここがいちばん大きく効きます。

**3. モデルの使い分け**

すべてをSonnet 5で処理する必要はありません。参考までに、他モデルの公開単価は次のとおりです。

- Claude Haiku 4.5: 入力1ドル / 出力5ドル
- Claude Opus 5: 入力5ドル / 出力25ドル
- Claude Fable 5: 入力10ドル / 出力50ドル

単純な分類・抽出・整形はHaiku 4.5に落とすと、9月以降のSonnet 5比で3分の1の単価になります。

なお、Claude 4.6以降のモデルは**1Mトークンのコンテキストウィンドウを標準価格のまま**使えると明記されています。長いコンテキストに対する追加の割増はありません。

## 筆者の見方

今回は「値上げ」というより、**期間限定の割引が予定どおり終わる**という話です。6月30日の公開時点から期限は告知され、価格ページにも9月1日からの数字が先に載っています。突然の変更ではありません。

とはいえ、従量課金で運用している人にとって請求が1.5倍になる影響は小さくありません。残り3週間でやることは2つだと考えます。直近1か月の使用量を1.5倍して見積もりを出すこと。そして、Batchとキャッシュに寄せられる処理が残っていないか棚卸しすることです。

特にプロンプトキャッシュは、単価の変動幅より効果が大きくなる場合があります。もともとやっておくべき最適化が期限で可視化された、という捉え方が実態に近いと考えます。
