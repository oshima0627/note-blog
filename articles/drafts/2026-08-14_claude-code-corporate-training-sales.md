# 半日30万円。Claude Code研修を法人に売る

半日の集合研修で30万〜50万円。丸1日の実践ワークショップなら80万〜150万円。これが2026年時点で公開されている、法人向け生成AI研修の価格帯です（出典: https://dotpro.net/lab/articles/ai-training-cost/ ）。

あなたが毎日Claude Codeを触っているなら、その半日分の中身は、もう手元にあります。足りないのは技術ではなく、**売り方と、値付けと、当日の運び方**です。

先に誠実さの宣言をします。本記事の数値・制度は**2026年8月14日時点**の確認値で、最新は各公式で要確認です。そして、Claude / Claude Code の法人研修を個人が受注した公開一次事例は、本記事の調査範囲では確認できませんでした。ですから架空の体験談や成功事例は一切書きません。公開されている相場・統計・公式制度と、実在する募集要項だけで組み立てます。

## 1. この記事は誰のためか——対象読者と、回収できる金額

先に読者を絞ります。時間を無駄にしてほしくないからです。

**読むべき人**

- Claude Code を業務で3ヶ月以上使い、自分なりの型ができている人
- 受託や個人開発で「単価の天井」を感じている人
- 人前で説明するのが、極端に苦手ではない人

**読まなくていい人**

- Claude Code をまだ触っていない人。教える中身が無いので順序が逆です
- 「登壇実績ゼロでいきなり大企業に売りたい」人。本記事は積み上げ型のルートを書きます
- 継続的な運用支援（月額顧問）を狙う人。それは別ルートです（当アカウントの導入支援コンサルの記事が対応します）

**金額の目安**

公開されている法人向け生成AI研修の相場は、形式でくっきり分かれます（出典: https://dotpro.net/lab/articles/ai-training-cost/ 、2026年7月21日更新）。

- eラーニング・動画視聴型: 1人あたり5万〜10万円
- 講師派遣・集合研修型: 1回30万〜150万円（半日の基礎セミナーで30万〜50万円、丸1日の実践ワークショップで80万〜150万円、対象人数10〜50名）
- 業務特化カスタマイズ型: 100万〜300万円超（5〜20名向け1日研修で50万〜70万円）

別の解説では、外部講師を招く場合の相場を1日あたり30万〜50万円としています（出典: https://ldcube.jp/blog/training257 ）。数字の幅は情報源ごとに違いますが、**「半日〜1日の集合研修が数十万円台」という中心はどの情報源でも共通**です。

ここが本記事の出発点です。時給換算で3,000円〜5,000円の受託をしている人と、半日30万円の研修を年に数本やる人とでは、同じスキルでも手取りが変わります。

**必要スキル**

- Claude Code の日常運用（CLAUDE.md、権限設定、MCP、サブエージェント）
- 自分の作業を「手順」として言語化できること
- 45〜90分を話し切れる程度の説明力。プレゼンの巧さは不要です
- 見積書・請求書を作れること（テンプレートで足ります）

**初期コスト**

ほぼゼロです。必要なのはスライド作成の時間と、研修用のサンプルリポジトリだけです。会場費・機材は発注側が負担するのが通例です。かかるのは交通費と、最初の実績を作るための無償登壇1〜2本ぶんの時間です。

正直に書きます。**最初の1件が一番遠い**です。ここを設計しないと、単価の話はすべて絵に描いた餅になります。第5節がその設計です。

## 2. なぜ今なのか——導入は進んだが、使いこなせていない

市場の状態を、推測ではなく公表データで確認します。

帝国データバンクが2026年3月17日〜31日に実施した調査があります。有効回答は1万312社です。生成AIを業務で活用している企業は**全体の34.5%**でした。規模別では大企業46.5%、中小企業32.4%、小規模企業28.0%です（出典: https://www.tdb.co.jp/report/economic/20260514-genai/ ）。

重要なのは、その次の数字です。同調査で挙がった活用上の課題は、上位から次の通りです。

- 情報の正確性: 50.4%
- 専門人材・ノウハウ不足: 41.3%
- 生成AIを活用すべき業務の範囲: 40.0%
- 情報漏洩のリスク: 33.5%
- トラブル時の責任所在などのルール整備: 25.5%

「導入したが、正しく使える人がいない」「どこに使えばいいかわからない」——これが上位2〜3位を占めています。**この2つはツールでは解けません。人が教えるしかない領域です。**研修という商品が成立する理由が、そのままデータに出ています。

そして2026年8月現在、Claude Code 側にも追い風があります。Anthropic は2026年8月7日に、Claude Code の既定の権限モードを **auto** に切り替えると発表しました。適用は **2026年8月14日**、対象は Pro / Max / Team プランの新規セッションです（出典: https://claude.com/blog/auto-mode-default-in-claude-code 、https://code.claude.com/docs/en/permission-modes ）。

auto モードは、ツール呼び出しのたびに人へ確認を出す代わりに、別の分類器モデルが実行前に各アクションを審査する仕組みです。技術的には妥当な変更です。ですが企業の情報システム部門から見ると、「エージェントが自動でコマンドを実行する」という一文が最初に目に入ります。

つまり、**「権限設計・ガードレールをどう組むか」が、企業側の具体的な不安として今まさに立ち上がっている**ということです。これは一般的な「ChatGPTの使い方」研修では答えられません。Claude Code を実際に運用している人だけが答えられる質問です。

ここが、あなたの差別化ポイントになります。

## 3. 価格の構造——誰がいくら払い、誰がいくら受け取るのか

研修の価格には、必ず2つの数字があります。**発注企業が払う額**と、**講師が受け取る額**です。この2つを混同すると、値付けを間違えます。

発注企業が払う額は、第1節に挙げた通り、半日30万〜50万円、1日80万〜150万円の帯です。ではその何割が講師に渡るのか。

ここは正直に書きます。**研修会社の講師報酬は、公開されていません。**

たとえば社員研修サービスのリスキルは、登録型の研修講師を業務委託で募集しています。扱うテーマには生成AI研修・DX研修も含まれます。講師未経験者も対象です。ただし報酬の記載は「講師給：経験等により変動」のみで、金額は明示されていません（出典: https://www.recurrent.jp/instructor_recruitings 、2026年8月14日確認）。

確実に言えることは1つです。**研修会社経由の案件には、営業費・企画費・教材費・管理費が乗っている。**したがって、講師の受取額は発注企業の支払額より下がります。これは中抜きが悪いという話ではありません。集客と契約と請求を代行してもらう対価です。

ここから導かれる戦略は、シンプルです。

1. **入口は研修会社経由**。実績ゼロでも登壇機会が手に入る。単価は下がる
2. **出口は直請け**。同じ半日でも受取額が跳ね上がる。ただし集客・契約・請求は全部自分でやる

最初から直請けを狙って何も起きないより、単価が下がっても登壇実績を作るほうが早いです。実績は次の交渉材料になります。逆に、実績が1本もない状態で企業に直接見積もりを出しても、判断材料がないので通りません。

## 4. 何を売るか——「ChatGPTの使い方」では勝てない

ここから具体論に入ります。まず商品設計です。

生成AI研修の市場は、すでに大手研修会社が押さえています。「生成AIとは」「プロンプトの書き方」「業務での使いどころ」——この構成の研修は、個人が後から参入して勝てる領域ではありません。カリキュラムも講師も揃っている相手に、同じ土俵で挑むことになります。

あなたが売れるのは、**大手が手を出しにくい、実装寄りで、環境依存が強い領域**です。具体的に3本用意します。

### 商品A: エンジニア向け「Claude Code 実装研修」（半日／実機演習）

対象は開発部門です。受講者が自分のPCで手を動かします。

- リポジトリを開いてから最初の1コミットまでを実演する
- CLAUDE.md をその場で書かせる。プロジェクト固有ルールをAIに守らせる仕組みを体験させる
- 権限設定・サンドボックス・拒否ルールを実際に設定させる
- 失敗例を見せる。「うまくいかないとき、何が起きているか」の読み方を教える

大手研修会社のカリキュラムがここまで実機に踏み込むのは容易ではありません。**環境構築の落とし穴を知っているかどうかが、そのまま商品価値**になります。

### 商品B: 情シス・管理部門向け「権限設計とガードレール」（2〜3時間）

対象は情報システム部門と管理職です。手は動かしません。判断のための研修です。

- auto モードの既定変更が自社に何をもたらすか
- 何が自動で通り、何がブロックされるか。既定でブロックされる操作の実例
- 組織として既定モードを固定する方法、設定ファイルの管理方針
- 機密コード・顧客データを扱うときの線引き

第2節で書いた通り、2026年8月14日以降、この質問は自然発生します。**問い合わせが来る前に商品として並べておく**のが要点です。

### 商品C: 非エンジニア部門向け「業務適用ワークショップ」（半日）

対象は営業・企画・管理部門です。帝国データバンクの調査で40.0%が挙げた「活用すべき業務の範囲」に、直接答える商品です。

- 参加者自身の業務を10個書き出させる
- 「AIに任せられる／任せてはいけない」で仕分けさせる
- 仕分けの基準を教える。正確性が求められる業務、責任所在が曖昧な業務は外す
- 上位3つを、その場で実際に試させる

この3本を「単品でも、組み合わせでも売れる」形にしておきます。A単体で半日、A+Bで1日、A+B+Cで2日構成。**1日構成にできると、価格帯が一段上がります**（第1節の相場で、半日30万〜50万円に対し1日80万〜150万円）。

### 作ってはいけない商品

- 「Claude Code 完全マスター講座」のような網羅型。準備工数が膨らみ、単価は上がりません
- 「成果を保証する」研修。第11節で述べる通り、保証は絶対にしません
- 特定バージョンの画面操作だけを詰め込んだ研修。Claude Code は更新が速く、半年で陳腐化します

## 5. 実績ゼロから最初の1件を取る——5ステップ

ここが本記事の中心です。順番を飛ばさないでください。

### ステップ1: 自社・現場で1回やる（費用ゼロ、所要2週間）

会社員なら自部署で、フリーランスなら取引先で、45〜60分の勉強会を開きます。無償で構いません。目的は3つです。

1. **話す型を作る**。想定より2倍時間がかかることを体感します
2. **質問を集める**。実際に出た質問が、次回のFAQになります
3. **証拠を残す**。日付・参加人数・テーマ・（可能なら）アンケート結果を記録します

この記録が、以降すべての営業資料になります。**「◯年◯月、社内20名向けにClaude Code研修を実施」の1行があるかどうかで、次の話の通りやすさが変わります。**

### ステップ2: 外部の勉強会・イベントで登壇する（費用ゼロ、所要1〜2ヶ月）

社内実績は「身内」と見なされます。外部での登壇を1本作ります。オンライン勉強会でも構いません。登壇資料は公開します。公開されたスライドは、そのまま提案書として使えます。

このとき、**必ず自分の連絡先と「法人研修も承ります」の1枚を末尾に入れます。**入れないと問い合わせは発生しません。

### ステップ3: 研修会社の登録講師に応募する（所要1〜3ヶ月）

登壇実績が2本できたら、登録型の研修会社に応募します。前述のリスキルは講師未経験者も対象とし、選考は「応募 → 書類送付 → 書類選考 → 面談 → 選考通過・研修」の流れです（出典: https://www.recurrent.jp/instructor_recruitings ）。同種の業務委託募集は Indeed 等でも継続的に出ています。

応募時に添えるものは3点だけです。

- 登壇実績（日付・対象・人数・テーマ）
- 研修カリキュラム案（商品A〜Cの見出しレベルで十分）
- 自己紹介（Claude Code の運用歴と、実際に作ったものの概要）

**単価は期待しないでください。**ここで買っているのは「企業の会議室で、知らない受講者20人を相手に半日を回した」という経験です。これは自主開催では絶対に手に入りません。

### ステップ4: スポットコンサルで「相談される側」に回る（並行して実施）

ビザスクのようなスポットコンサルサービスでは、1時間単位で企業からの相談を受けられます。生成AIの業務活用をテーマにしたアドバイザーも登録されています（出典: https://visasq.co.jp/lp/interview_service01 ）。謝礼水準や手数料率は第三者の解説記事でしか確認できず、公式ページでは金額を確認できませんでした。金額は必ず自分で規約を確認してください。

金額目的ではありません。狙いは**企業が今どこで詰まっているかを一次情報で仕入れること**です。ここで得た質問が、そのまま研修カリキュラムの改訂材料になります。

### ステップ5: 直請けに切り替える（所要6ヶ月〜）

実績が5本を超えたあたりから、直接依頼が現実的になります。経路は3つです。

1. **登壇先からの逆流入**。受講者の所属企業から、次年度の研修として声がかかる形
2. **note / X からの流入**。研修メニューと実績を固定ポストにまとめておく
3. **既存の受託先へのアップセル**。開発を請けている企業に「御社の他部署向けに研修を」と提案する

3番目が最短です。**すでに信頼関係があり、稟議の通し方も知っている相手**だからです。開発案件が一段落したタイミングで出すのが自然です。

## 6. 見積書の作り方——「講師料一式」と書かない

直請けで最も事故が起きるのが見積もりです。「講師料 一式 300,000円」と書くと、必ず値切られます。相手の稟議担当者に、内訳を見せる必要があります。

分解して書きます。

- 事前打合せ（1回90分／オンライン）
- カリキュラム個別調整（受講者の職種・既存環境に合わせた改訂）
- 教材作成（スライド、演習用リポジトリ、当日配布資料）
- 当日登壇（半日3時間、質疑込み）
- 事後フォロー（研修後2週間、メールでの質問対応）
- 交通費・宿泊費（実費、別途）

**分解すると、値段が「登壇時間3時間で30万円」ではなくなります。**準備工数が見えるからです。実際、初回の教材作成には20〜40時間かかります。時給換算で考えれば妥当な金額であることが、相手にも自分にも見えます。

見積書に必ず入れる条項は次の4つです。

- **再演料**: 同一内容を別部署で再実施する場合の金額（初回の50〜70%が目安）。これを入れておかないと、2回目をタダでやらされます
- **キャンセル規定**: 実施日の何日前からいくら発生するか。14日前50%、7日前100%などを明記します
- **録画・二次利用の可否**: 録画を社内eラーニングに転用されると、以降の再演料が消えます。「録画は当日参加できなかった方向けに3ヶ月間のみ」等の条件を書きます
- **受講人数の上限**: 演習型は人数が増えるとフォローが破綻します。上限20名、超過分は1名あたり◯円と書きます

金額を下げてほしいと言われたときは、**単価を下げず、範囲を削ります。**事後フォローを外す、事前打合せを1回に減らす、演習を減らして講義型にする。値引きに応じると、次回もその金額が基準になります。

## 7. 契約と税務——ここを知らないと手取りが1割減ります

個人が法人から講師料を受け取る場合、**源泉徴収**が発生します。知らないと「請求額と振込額が違う」と慌てます。

原稿料・講演料等を個人へ支払う際、支払者には源泉徴収の義務があります。税率は所得税10%＋復興特別所得税0.21%の合計で **10.21%** です。同一人への1回の支払額が100万円を超える部分は **20.42%** になります（出典: https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2792.htm 、https://ayusawa-partners.jp/column/houshuu-ryoukin-genkou-kouen ）。

計算例です。

- 講師料30万円の場合: 300,000 × 10.21% = 30,630円が源泉徴収され、振込は269,370円
- 講師料120万円の場合: (1,200,000 − 1,000,000) × 20.42% + 102,100円 = 142,940円が源泉徴収

**取られっぱなしではありません。**源泉徴収された金額は所得税の前払いなので、確定申告で精算されます。年間の所得次第では還付になります。

消費税の扱いにも注意点があります。報酬額に消費税が含まれている場合、原則として**消費税込みの金額が源泉徴収の対象**になります。ただし請求書で報酬額と消費税額が明確に区分されていれば、報酬額のみを対象にできます（出典: https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2792.htm ）。

つまり**請求書は必ず「講師料 300,000円／消費税 30,000円／合計 330,000円」と分けて書きます。**一行で「330,000円」と書くと、源泉徴収額が33,693円になり、3,000円ほど手取りが減ります。

契約形態は業務委託契約です。確認すべき条項は次の通りです。

- **秘密保持**: 研修中に受講者の実コードを見る可能性があります。NDAは必ず結びます
- **成果物の権利**: 教材の著作権は講師に残す形にします。残さないと、同じ教材を他社で使えません
- **競業避止**: 研修会社経由の場合、当該企業への直接営業を禁じる条項が入ることがあります。ステップ5の逆流入に直結するので、必ず読みます
- **再委託の可否**: 通常は不可です

インボイス制度への対応も確認されます。免税事業者のままだと、発注側が仕入税額控除を使えず、その分の値引きを求められることがあります。研修を継続的な収入源にするなら、登録の要否は税理士に確認してください。

## 8. 助成金を「値引きの代わり」に使う

価格交渉で押されたとき、値引き以外のカードを持っておきます。助成金です。

厚生労働省の**人材開発支援助成金（事業展開等リスキリング支援コース）**があります。新規事業やDX・GXに向けた社員研修の経費を助成する制度です。解説記事によれば、経費助成率は中小企業75%・大企業60%です。訓練期間中の賃金助成は1人1時間あたり中小企業1,000円・大企業500円とされています。本コースは令和8年度末（2027年3月31日）で終了予定です（出典: https://hojyokin-portal.jp/columns/jinzaikaihatsu_reskilling 、制度の公式情報は https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/koyou/kyufukin/d01-1.html ）。

助成率・要件は年度ごとに変わります。**必ず厚生労働省の最新の詳細版パンフレットで確認してください。**厚労省サイトには「令和8年度版 事業展開等リスキリング支援コースのご案内（令和8年8月3日版）」が掲載されています（2026年8月14日確認）。

営業上の使い方は簡単です。「30万円を25万円に」と値引くのではなく、**「この研修は助成金の対象になり得ます。実質負担は御社の想定より下がる可能性があります」**と伝えます。単価を守ったまま、相手の負担感だけを下げられます。

ただし2点、絶対に守ってください。

1. **申請の代行はしない**。社会保険労務士の業務範囲に触れます。「対象になり得ます」までに留め、手続きは相手方と社労士に委ねます
2. **「必ず受給できる」と言わない**。要件は企業側の状況で変わります。断言すると、不支給時に責任問題になります

## 9. 当日の落とし穴——技術以外で失敗する

研修が失敗するのは、たいてい内容ではなく環境です。事前打合せで潰しておく項目を挙げます。

**環境が用意できない**

企業の貸与PCには、そもそもClaude Codeを入れられないことがあります。管理者権限がない、外部ツールの導入申請が通っていない、社内ネットワークが特定ドメインへの通信を遮断している——どれも珍しくありません。

対策は事前打合せでの確認です。**「当日までに全員のPCでClaude Codeが起動し、簡単なコマンドが1つ通る状態」を、発注側の宿題として明文化します。**見積書にも「受講者の実行環境は貴社にてご準備ください」と書きます。ここを曖昧にすると、研修の前半2時間が環境構築で消えます。

用意できない場合の代替も準備します。講師のマシンを画面共有して実演する講義型に切り替える、演習は擬似コードで行う、といった形です。**「環境が無いなら中止」ではなく「講義型に切り替える」と提案できると、案件を落としません。**

**受講者のレベルが揃わない**

事前アンケートを取ります。「ターミナルを日常的に使うか」「Gitのブランチ操作ができるか」の2問で十分です。回答が割れたら、演習をペア作業にします。

**機密コードを扱えない**

自社リポジトリで演習したい、と言われることがあります。ですが講師が見てよいコードかは別問題です。**演習用のサンプルリポジトリを自分で用意しておきます。**これがあると「まずサンプルで手順を覚え、後日ご自身のコードで再現」という流れに逃がせます。

**「で、うちの業務にどう使うんですか」に答えられない**

これが最も多い質問です。事前打合せで、受講部署の業務を3つ聞き出しておきます。当日その3つを例に使うと、満足度が明確に変わります。

**時間が足りない**

演習は必ず想定より遅れます。**カットしてよいセクションを、事前に2つ決めておきます。**その場で判断すると、必ず一番大事な後半が削れます。

## 10. リピートと単価の上げ方

研修は単発で終わると割に合いません。準備工数が初回に集中するからです。2回目以降で回収します。

**同一企業内での横展開**

1部署で実施したら、他部署に広げます。教材はほぼ流用でき、準備工数は初回の2〜3割です。再演料を見積書に入れておいた意味がここで出ます。

**階層を変える**

商品Aを開発部門でやったら、次は商品B（情シス・管理職向け）を提案します。対象者が変われば、別の予算枠から出ます。

**年間契約に寄せる**

四半期ごとの実施を年間パッケージにします。個別発注より合計金額は上がり、こちらは日程を先に押さえられます。

**運用支援へつなげる**

研修の最後に必ず出るのが「これを社内に定着させるにはどうすれば」という質問です。ここが月額の導入支援・顧問契約への入口です。研修は単発で終わる商品ではなく、**継続契約のフロントエンド**として設計するのが本筋です。この続きは当アカウントの導入支援コンサルの記事で扱っています。

**単価そのものを上げる**

上げる根拠は3つだけです。登壇実績の本数、受講者アンケートの数値、そして自分の実装実績です。**「Claude Codeで◯◯を作って納品している人が教える」**は、専業講師には出せない差別化です。受託や個人開発を続けながら講師をやる意味は、ここにあります。

## 11. リスクと注意点——正直に書きます

**1. 陳腐化が速い**

Claude Code は更新頻度が高く、権限モードのような基本仕様さえ変わります（2026年8月14日の既定変更がまさにそれです）。教材は3ヶ月ごとに見直す前提で作ります。画面のスクリーンショットに依存した教材は、特に早く腐ります。

**2. 「成果」は保証できない**

「研修後に開発速度が◯%上がる」とは言わないでください。効果は受講者の習熟度と業務内容に左右されます。保証すると、達成できなかったときに契約不適合を問われる余地が生まれます。約束するのは**内容と時間であって、成果ではありません。**

**3. 企業のAI利用ポリシーと衝突する**

「外部AIサービスへの業務データ入力禁止」というポリシーを持つ企業は珍しくありません。事前に確認せず演習を組むと、当日詰みます。ポリシーの有無は事前打合せの必須確認項目です。

**4. 情報の正確性リスク**

帝国データバンクの調査で企業側の課題1位（50.4%）が「情報の正確性」だった点は、講師側にも跳ね返ります。**生成AIの出力を検証せずに教えないでください。**料金・仕様・規約は、研修当日に近い日付で再確認します。古い情報を教えると、その1点で信頼を失います。

**5. 競業避止条項**

研修会社経由の案件では、当該企業への直接営業が制限されることがあります。契約書を読まずにステップ5（直請け）へ進むと、契約違反になります。

**6. 収入の変動が大きい**

研修需要には季節性があります。年度初め（4〜6月）と下期開始（10月）に集中しやすく、閑散期があります。研修だけを収入の柱にせず、受託や個人開発と組み合わせてください。
