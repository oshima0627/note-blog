# Claude Codeの週次上限50%増、8月19日まで延長（7月19日終了予定が変更）

*2026年7月26日時点の情報です。使用量制限や料金は変わりやすいため、最新は必ず公式で確認してください。*

**この記事でわかること**

- Claude Codeの「週次使用量50%増」がいつまで続くのか（結論：2026年8月19日まで延長）
- 対象になるプラン・ならないプラン
- 8月19日以降に向けて、いま確認しておきたいこと

## 何が起きたのか

Anthropicは、Claude Codeの**週次使用量の上限を50%引き上げるプロモーション**を実施しています。当初この増量は2026年7月19日で終了する予定とされていましたが、**2026年8月19日まで延長**されました。

公式サポートページ（記事タイトルも「Claude Code May–August 2026 Weekly Limits Promotion」に更新済み）には、次のように記載されています。

> 「2026年5月13日から2026年8月19日まで、Claude Codeの週次使用量の上限が50%高くなります」

つまり、当初の「7月19日で通常水準に戻す」という案内は撤回され、増量期間がもう1か月ほど延びた形です。参加に特別な操作は不要で、対象プランなら自動的に適用されます。

## 対象になるプラン・ならないプラン

公式の記載を整理すると、次のとおりです。

- 対象：Proプラン、Maxプラン、Teamプラン、およびEnterpriseの旧「シート単位（座席課金）」ユーザー
- 対象外：無料（Free）プラン、Enterpriseの従量課金（consumption-based）シート

自分がどのプランに該当するかは、契約形態によって異なります。特にEnterpriseはシート単位か従量課金かで扱いが分かれるため、不明な場合は管理者や請求情報で確認してください。

## 何が「50%増」なのか（誤解しやすい点）

このプロモーションで増えるのは、あくまで**週次（weekly）の使用量上限だけ**です。公式ページは次の点を明記しています。

- 5時間ごとの使用量上限（5-hour usage limits）はこのプロモーションの対象外
- 増えるのは週次の上限のみ

そのため「短時間に一気に使える量が増える」わけではなく、「1週間トータルで使える量が増える」という理解が正確です。

また、対象は**Claude Codeだけ**です。公式は「CLI、IDE拡張、デスクトップ、Web版のどこで使っても、Claude Codeに対して50%増が適用される」としています。Claudeのチャット（Web/デスクトップ/モバイル）そのものの上限が増えるわけではない点に注意してください。

## 読者（Claude Codeユーザー）への影響

- 当面（8月19日まで）は、これまでどおり50%増の週次枠を使えます。今すぐ使い方を変える必要はありません。
- ただし、公式は「2026年8月19日以降は、Claude Codeの週次使用量の上限が通常水準に戻る」と明記しています。プランや請求の変更はありませんが、**8月20日以降は使える週次量が実質的に減る**と考えておくのが安全です。
- 重い自動化（サブエージェントの多用、長時間の連続実行など）を回している場合、9月以降に「先週より早く上限に達する」体感が出る可能性があります。

これは筆者の見方ですが、増量が2回にわたって案内された経緯を踏まえると、期限直前にさらに延長・変更される可能性もゼロではありません。最終的な扱いは公式サポートページで都度確認するのが確実です。

## 8月19日に向けてできること

事実の範囲でできる備えは限られますが、次の2点は有効です。

- **`/usage` で自分の消費内訳を把握する**：Claude Codeには使用量の内訳（スキル・サブエージェント・プラグイン・MCPサーバー別など）を表示する `/usage` コマンドがあります。何が枠を食っているかを先に知っておくと、上限が戻った後の調整がしやすくなります。
- **重い処理の見直し**：常時走らせている自動実行やサブエージェントのループがあれば、本当に必要な頻度か棚卸ししておくと、通常水準に戻ったときの余裕が変わります。

## まとめ

Claude Codeの週次上限50%増は、当初の7月19日から**2026年8月19日まで延長**されました。対象はPro・Max・Team・旧シート単位Enterpriseで、5時間制限は対象外、増えるのは週次のみです。8月19日以降は通常水準に戻る予定なので、いまのうちに `/usage` で消費傾向を把握しておくと安心です。
