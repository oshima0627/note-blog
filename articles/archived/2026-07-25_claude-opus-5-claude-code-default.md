# Claude Opus 5登場：Claude Codeの既定Opusが刷新、料金は据え置き

**この記事は2026年7月24日時点の情報です。** 料金・仕様は変わりやすいため、最新情報は必ずAnthropic公式でご確認ください。

**この記事でわかること**

- 新モデル「Claude Opus 5」の発表内容と、料金が据え置かれたこと
- Claude Codeで既定のOpusモデルが切り替わったこと（バージョンと時期）
- 使ううえで押さえたい挙動の変化（thinking既定オン・effort・自己検証）

## Claude Opus 5とは

Anthropicは2026年7月24日、新モデル「Claude Opus 5」を発表しました。公式ドキュメントでは、前世代のOpus 4.8からの「段階的ではなく、非連続的な改善（step-change improvement）」と位置づけられています。

特に伸びたとされる領域は次のとおりです。

- 深い推論（長い問題の連鎖を通した多段階の分析）
- エージェント的なコーディングと長時間タスク（複数ファイルの機能実装や大きなリファクタを、途中で止めずに進める）
- テスト時計算のスケーリング（かける「effort」を上げるほど結果が良くなる度合い）
- コードレビュー・バグ発見（1回のパスで実バグを高い割合で見つけ、誤検出が少ない）

コンテキストウィンドウ（一度に扱える文章量）は100万トークンで、これが既定かつ最大です。出力の上限は12万8千トークン、そして「thinking（思考）」が既定でオンになっています。

**Claude Codeユーザーへの影響**: 大きなコードベースを丸ごと読ませたり、長い作業を任せたりする用途で扱いやすくなったとされています。特にエージェント的なコーディングは、公式が明確に「勝ち筋」として挙げている領域です。

出典: Anthropic公式発表・公式ドキュメント（末尾リンク参照）

## Claude Codeで既定のOpusモデルに

読者にとって直接的な変化はここです。Claude Codeの更新情報によると、**バージョン2.1.219（2026年7月24日）でClaude Opus 5がClaude Codeの既定のOpusモデルになった**と案内されています。1Mコンテキスト付きです。

あわせて、同バージョンでは次の変更も入っています。

- `/model`ピッカーでのOpus表示が「Opus（1M context）」に統一
- Fast modeの対象からOpus 4.7を外し、`/fast`はOpus 5とOpus 4.8に適用
- サブエージェントが入れ子でサブエージェントを生成できる深さの既定が、1から3に拡大

**Claude Codeユーザーへの影響**: 設定でモデルを固定していない場合、Claude Codeを更新して使うと、Opusを選んだときの実体がOpus 5に変わっている可能性があります。「いつもと挙動が違う」と感じたら、まず`/model`で現在のモデルを確認するとよいでしょう（筆者の見方）。

## 料金は据え置き（2026年7月24日時点）

コスト面での要点は「性能は上がったが料金は変わっていない」ことです。

- API標準料金: 入力100万トークンあたり5ドル / 出力100万トークンあたり25ドル（Opus 4.8と同額）
- Fast mode（研究プレビュー）: 入力10ドル / 出力50ドル。Claude API限定で、既定の約2.5倍の速度とされています

**Claude Codeユーザーへの影響**: API従量課金で使う場合、同じ単価でより良い結果が期待できる形です。公式は「前世代と同じコストで大きく改善」と説明しています。サブスクリプション（Pro / Max等）で使う場合は、単価ではなくプランの利用上限の中で使う形になります。最新の料金・上限は変わりやすいため、公式の料金ページでご確認ください。

## 使ううえで押さえたい挙動の変化

Opus 5は、Opus 4.8から挙動がいくつか変わっています。移行時に戸惑わないよう、主な点を挙げます。

- **thinkingが既定でオン**: Opus 4.8では明示的に指定しない限り思考なしで動きましたが、Opus 5では既定で思考します。`max_tokens`は思考と出力の合計にかかる上限なので、値を見直すとよいとされています。
- **effort（努力度）の比重が増す**: 思考の深さは`low` / `medium` / `high` / `xhigh` / `max`の5段階で、既定は`high`です。Opus 5はeffortを上げるほど結果が良くなりやすいとされ、評価に応じて上下させる運用が推奨されています。
- **思考オフには制約（破壊的変更）**: 思考の無効化は、effortが`high`以下のときだけ受け付けられます。`xhigh`または`max`で思考を無効化するとエラー（400）になります。これはOpus 4.8からの破壊的変更です。
- **自己検証するので検証指示は外す**: Opus 5は指示しなくても自分の作業を検証するため、過去のモデル向けに書いた「最後に検証ステップを入れて」等の指示は、過剰な検証を招くとして削除が推奨されています。

**Claude Codeユーザーへの影響**: 応答が長めになる、進捗をよく報告する、サブエージェントに任せやすくなる、といった違いも公式に挙げられています。CLAUDE.mdやカスタム指示に古い「検証しろ」系の文言が残っている場合は、見直すと快適に使えるかもしれません（筆者の見方）。

## まとめ

- 2026年7月24日にClaude Opus 5が登場。Opus 4.8からの非連続的な改善とされ、1Mコンテキスト・thinking既定オン
- Claude Codeではv2.1.219で既定のOpusモデルに。`/fast`の対象もOpus 5へ
- API料金は入力5ドル/出力25ドルでOpus 4.8と同額。Fast modeは10ドル/50ドル（API限定）
- 移行時は「thinking既定オン」「effortの5段階」「思考オフの制約」「自己検証」に注意

状況は動いています。料金・仕様・既定モデルの扱いは、最新情報を公式でご確認ください。
