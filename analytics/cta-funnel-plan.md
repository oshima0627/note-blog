## 貼るCTAの型

```

（記事の締めから自然につながる1文）

▼ まず1本試すなら（500円）
https://note.com/oshima0627/n/<入口の key>
```

URLを単独行に入力して Enter すると note が埋め込みカードに変換する。

## 実施手順（note エディタ／検証済み）

1. `https://editor.note.com/notes/<key>/edit/` を開く（**数値ID ではなく key**。
   数値IDのURLはエディタが空で立ち上がり、保存すると記事を壊す恐れがある）
2. 7〜8秒待つ。本文が出るまで**絶対に保存しない**
3. 本文の**最終行を実際にマウスでクリック**する → `End` → `Return` を2回
4. `getSelection()` の親チェーンが `P` 直下（BLOCKQUOTE/LI でない）ことを確認する
5. CTA を type で入力。URL行のあとは4秒待って埋め込みカードの生成を待つ
6. 「公開に進む」→「更新する」
7. `/api/v3/notes/<key>` を叩いて `ctaLinks>=2` と `status:"published"` を確認

## 落とし穴（実際に踏んだ）

- **JavaScript で `getSelection()` にカーソルを置いてから type すると壊れる。**
  Enter が全部無視されて1行に連結され、英数字が脱落する
  （「▼ まず1本試すなら（500円）」→「▼まず本試すなら（円）」）。
  **必ず実際のマウスクリックでフォーカスを取ること。**
  やらかしたら Ctrl+Z を40回。公開版は 更新する を押すまで無傷
- 記事末尾が引用ブロックや箇条書きのことが多い。`Return` 2回で抜けてから書く
- エディタ右上の文字数カウンタは遅延する。判定には使わない。
  `document.querySelector('.ProseMirror').innerText` を見る
- 「更新する」でも**公開日は変わらない**（検証済み）
